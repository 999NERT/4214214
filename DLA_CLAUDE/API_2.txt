# UE 5.8 Sequence FBX Exporter - Project Context

## Cel projektu

Stworzenie narzędzia w Pythonie dla Unreal Engine 5.8, które umożliwia eksport aktualnie otwartego Level Sequence do FBX jednym kliknięciem.

Docelowo narzędzie ma działać z poziomu menu **Tools** lub jako Editor Utility i nie wymagać ręcznego zaznaczania elementów w Sequencerze.

---

# Unreal Engine

Version:

```
5.8.0-55116800+++UE5+Release-5.8
```

# Dostępne klasy Python

## SequencerTools

Klasa istnieje.

```python
hasattr(unreal, "SequencerTools")
```

Wynik:

```
True

```

# Export FBX

Pomoc z Pythona:

```python
help(unreal.SequencerTools.export_level_sequence_fbx)
```

Wynik:

```
X.export_level_sequence_fbx(params) -> bool

Export Passed in Bindings and Tracks to FBX

Args:
    params (SequencerExportFBXParams)

Returns:
    bool
```

Funkcja przyjmuje WYŁĄCZNIE:

```
SequencerExportFBXParams
```

---

# SequencerExportFBXParams

Dostępne pola:

```
bindings

tracks

sequence

root_sequence

world

fbx_file_name

override_options
```

Lista została uzyskana przez:

```python
params = unreal.SequencerExportFBXParams()

for p in dir(params):
    if not p.startswith("_"):
        print(p)
```

---

# Założenia projektu

Program ma:

- pobrać aktualnie otwarty Level Sequence
- pobrać Root Sequence
- pobrać World
- zebrać wszystkie Bindingi
- zebrać wszystkie Tracki
- utworzyć SequencerExportFBXParams
- wywołać export_level_sequence_fbx()
- zapisać FBX do wskazanego folderu

# Informacje dla AI

Nie należy używać:

```
MovieSceneToolHelpers
```

ponieważ nie jest dostępny w Python API UE 5.8.

Eksport należy wykonywać wyłącznie przez:

```python
unreal.SequencerTools.export_level_sequence_fbx(params)
```

gdzie params jest instancją:

```python
unreal.SequencerExportFBXParams()
```

Projekt ma być wykonany wyłącznie w Pythonie (bez C++), jeśli API UE 5.8 na to pozwala.
