# SequencerExportFBXParams

Tworzenie

```python
params = unreal.SequencerExportFBXParams()
```

---

## Dostępne pola

```
bindings
tracks
sequence
root_sequence
world
fbx_file_name
override_options
```

---

## Opis pól

### bindings

Lista Bindingów eksportowanych do FBX.

---

### tracks

Lista Tracków eksportowanych do FBX.

---

### sequence

Aktualny eksportowany Sequence.

---

### root_sequence

Root Sequence.

---

### world

Aktualny World.

---

### fbx_file_name

Ścieżka zapisu FBX.

Przykład

```python
params.fbx_file_name = r"D:\Exports\Test.fbx"
```

---

### override_options

Opcje eksportu FBX.

Do zbadania.

# Cel końcowy

Napisać funkcję:

```python
export_current_sequence_to_fbx(output_path)
```

która:

1. Pobiera aktualny Level Sequence.
2. Automatycznie zbiera wszystkie Bindingi.
3. Automatycznie zbiera wszystkie Tracki.
4. Tworzy SequencerExportFBXParams.
5. Wywołuje:

```python
unreal.SequencerTools.export_level_sequence_fbx(params)
```

6. Zwraca:

```python
True
```

lub

```python
False
```

bez jakiejkolwiek ręcznej ingerencji użytkownika.
