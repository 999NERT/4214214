--- menu.py ---

2. uninstall_menu() - usuwa menu

SCHEMAT DZIAŁANIA:
- Gets ToolMenus singleton
- Extends MainFrame.MainMenu (główny pasek menu)
- Calls add_sub_menu("Exporter", ...) - TWORZY SUBMENU

- Dodaje entry do submenu

CALLBACK: from exUE5.menu import _run_export; _run_export()

WAŻNE: Funkcja _run_export() znajduje się w tym pliku i:
- Załadowuje config.json
- Tworzy folder D:/Exports
- Wywołuje export_current_sequence() z exporter.py
- Loguje wynik do Output Log UE5

--- exporter.py ---
FUNKCJA: Czysta logika exportu FBX
STATUS: STABILNY I ZWERYFIKOWANY

Zawiera funkcje:
- load_config() - czyta config.json

export_current_sequence() loguje każdy krok i zwraca dict z wynikami.

WERSJA: UE 5.8.0-55116800+++UE5+Release-5.8

KLUCZOWE KLASY/METODY:

unreal.ToolMenus
  - get() - Singleton instancji
  - is_menu_registered(name) - Sprawdź czy menu istnieje
  - find_menu(name) - Znajdź menu
  - remove_menu(name) - Usuń menu
  - extend_menu(parent_name) - Rozszerz/utwórz menu
  - refresh_all_widgets() - Odśwież UI

unreal.ToolMenu (zwracane z extend_menu lub add_sub_menu)
  - add_menu_entry(name, ToolMenuEntry) - Dodaj entry
  - add_sub_menu(name, label, tooltip, help_text) - Utwórz submenu
  - add_section(name, label) - Dodaj sekcję
  - get_menu_entries() - NIEDOSTĘPNE! (AttributeError)

unreal.ToolMenuEntry
  - type = MultiBlockType.MENU_ENTRY (ustaw typ)
  - set_label(text) - Ustaw etykietę
  - set_tool_tip(text) - Ustaw tooltip
  - set_string_command(command_type, command, code) - Ustaw callback

unreal.SequencerTools
  - export_level_sequence_fbx(params) - Główna funkcja exportu

unreal.SequencerExportFBXParams
  - sequence, output_filename, allow_root_mot, export_cameras, etc.

HIERARCHIA MENU:
- "MainFrame.MainMenu" = główny pasek menu (File, Edit, Window, Tools, Build, Platforms...)
- "MainFrame.MainMenu.Exporter" = nowe submenu "Exporter"
